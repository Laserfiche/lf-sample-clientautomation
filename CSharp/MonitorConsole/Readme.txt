About the MonitorConsole sample project:

This project demonstrates how the ClientAutomation SDK can be used to find all open instances
of the Laserfiche client. When run, this program runs in a loop and prints details about all
open client windows. For each entry listing window, it prints the current user, current repository,
current folder and a list of all selected entries. For each doc viewer window, it prints the
current user, current repository, current page and a list of all selected thumbnails.
